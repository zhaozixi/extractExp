# extractExp（萃取经验助手），让 AI 记住你的每一次成长

> 专为普通用户设计，无需编程，只需三句人话。  
> 所有数据本地存储，完全离线，无需 API Key。

## 为什么开发 extractExp（萃取经验助手）？

### 一、现在的工具，只帮你"记住"，不帮你"成长"

像 Workbuddy 这类工具，核心功能是：你解决了一个问题，把操作步骤记下来，存成一个"技能"（Skill）。下次遇到同样的问题，直接调用这个技能，一键搞定。

这很好，但不够好。

因为你真正需要的，不是把"怎么填表格"记下来，而是把"遇到陌生表格时该怎么分析"的思考方法记下来。

**举个例子：**

现在的技能存的是：`打开A网站 → 复制B列数据 → 粘贴到C表格 → 用公式求和`

你真正想存的是：`当面对一堆杂乱数据时，先看表头含义 → 再判断数据类型 → 然后决定用哪种清洗方法 → 最后验证结果是否合理`

前者换了网站就废了，后者换个数据源照样能用。

### 二、核心矛盾：技能是"死的"，思考是"活的"

人类学习的过程，从来不是背步骤，而是提炼规律。

你解决了一个爬虫报错，下次遇到数据库报错，你依然能处理——因为你记住的不是"改哪行代码"，而是"先看错误日志 → 再定位问题范围 → 然后查文档试方案 → 最后验证修复结果"这一套解决问题的通用套路。

但现在的工具，把你活的思考过程，压缩成了一个死的步骤清单。这就像：

- 你把一位大厨的菜谱记下来，不等于你学会了烹饪
- 你把一位棋手的每一步棋记下来，不等于你学会了下棋

**真正有价值的是背后的决策逻辑，而不是表面的操作轨迹。**

### 三、这个工具想做什么？

extractExp 不是用来存"步骤"的，而是用来存"经验"的。

它帮你把一次具体的解决问题过程，拆成三个层次来保存：

| 层次 | 存什么 | 打个比方 |
|------|--------|----------|
| **第一层 (L1)** | 这次具体怎么做的 | 相当于记日记："今天修好了热水器，换了根管子" |
| **第二层 (L2)** | 这类问题通用的策略 | 相当于总结："电器不工作，先查电源→再查管道→再查核心部件" |
| **第三层 (L3)** | 最根本的思考原则 | 相当于顿悟："修任何东西，都要先找到那个'最小可验证单元'，先确认它正常，再往外排查" |

存了 L1，你只能解决"换管子"这一个问题。
存了 L2，你能修所有水电燃气类问题。
存了 L3，你不仅能修电器，还能修电脑、修流程、修人际关系——因为底层逻辑通了。

### 四、所以，这个工具真正解决的是：

**把"具体经验"变成"通用智慧"的问题。**

它不是帮你存更多技能，而是帮你的每一次解决问题，都变成下一次解决问题的"底牌"，而不是"病历"。

**让人越用越聪明，而不是越用越依赖死记硬背。**

## ⚠️ 使用前提
- 请配合 **Workbuddy 的 Craft 模式** 使用。
- 电脑需安装 Python 3.8+。并确保 `python` 命令在 PATH 中。可以执行 `python --version` 检查。或者 where python 查看安装路径。

## 快速开始
1. 下载并解压本项目到英文路径（例如 `D:/extractExp` 或 `/home/xxx/extractExp`）。
2. 双击 `scripts/install.bat` 安装依赖（Windows），Mac/Linux 用户手动执行 `pip install -r scripts/requirements.txt`。
3. 打开 Workbuddy → 切换到 **Craft 模式** → 导入 `extractExp/SKILL.md`。
4. 在聊天框输入：`设置萃取经验助手路径为 D:/extractExp`（注意斜杠方向）。
5. 等待初始化完成（首次会自动下载约188MB的本地模型）。

## 三句人话，开启无限记忆
- **"保存这个经验"** → AI 自动整理步骤、策略、坑点，永久保存并关联相似经验。
- **"帮我想想"** → 遇到新问题，AI 秒搜你的历史智慧，像老师傅一样给建议。
- **"整理知识"** → 每周一次，AI 自动归纳出通用方法论，让经验升级。

## 进阶：知识图谱与冲突检测
- 每次保存时，AI 会自动提取关键实体和关系（例如"Selenium 解决了 懒加载问题"），构建个人知识图谱。
- 整理知识时，如果新发现与旧策略冲突，AI 会提醒你更新，防止知识过时。

## 数据所有权
所有数据（经验、模型、图谱）均存储在 `exps/` 目录下，拷贝整个项目文件夹到其他电脑可直接使用。

## 常见问题
- **首次初始化卡住？** 模型约188MB，请耐心等待下载。
- **提示 `python` 不是内部命令？** 请安装 Python 时勾选"Add to PATH"。
- **Mac/Linux 路径？** 使用正斜杠，如 `/home/xxx/extractExp`。
